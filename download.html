Windows

  • Windows 10 or 11, 64-bit (x64)
  • Installer: .exe or .msi
  • Microsoft Edge WebView2 (included with Windows 11)

First time: if Windows says “Windows protected your PC”, choose More info, then Run anyway. A Microsoft Store version is on its way.

Your system

macOS

  • Universal build: Apple silicon and Intel
  • Installer: .dmg
  • Quick capture uses Cmd+Shift+Space
Coming soon · Get early access

First time: macOS blocks the app because it isn’t notarized yet. Open it once, click Done, then go to System Settings → Privacy & Security and click Open Anyway.

Your system

Linux

  • 64-bit (x64)
  • Packages: .AppImage, .deb or .tar.gz
  • A desktop with a system tray works best
Coming soon · Get early access

AppImage: make it executable (chmod +x), then run it. On Debian or Ubuntu, the .deb installs it like any other app.

After you install

  1. Open it once

    Work Companion starts in your system tray (menu bar on macOS) and your character appears in a corner of the screen.

  2. Open the dashboard

    Set your work hours, character and reminders. Connecting Google Calendar and AI is optional.

  3. Try quick capture

    Press Ctrl+Shift+Space (Cmd on macOS) and type a note for today’s log.
